# بوت التداول — المرحلة 1: الباكتيست

## الفكرة
- الاستراتيجية: اتجاه صاعد على المدى الطويل (SMA50 > SMA200) + ارتداد بعد تشبع بيعي (RSI) مؤكد بـMACD وحجم تداول أعلى من المتوسط.
- الدخول قرب منطقة دعم إن وُجدت (يقلل نسبة المخاطرة للصفقة).
- الخروج: وقف خسارة ديناميكي حسب تذبذب السهم (ATR)، أو تحقيق هدف عند أقرب مقاومة، أو خروج مبكر عند انعكاس زخم MACD.
- حجم كل صفقة يُحسب تلقائيًا بحيث لا تتجاوز خسارتك نسبة ثابتة من رأس المال (افتراضي 1%) — هذا أهم جزء لحماية رأس المال الصغير.

## التشغيل
```bash
pip install -r requirements.txt
python run_backtest.py AAPL --capital 1000 --risk 0.01 --period 3y
```

جرّب أي رمز سهم أمريكي، وغيّر `--capital` و`--risk` و`--period` حسب رغبتك.

**ملاحظة:** هذا الكود يجيب البيانات من Yahoo Finance عبر مكتبة `yfinance` — يشتغل عادي على جهازك الشخصي، لكن ما يشتغل داخل بيئة التطوير الحالية لأنها بدون وصول لشبكة الإنترنت العامة. اختبرت منطق الكود بالكامل (المؤشرات، توليد الإشارات، حساب حجم الصفقة، تنفيذ وقف الخسارة/الهدف) على بيانات اصطناعية وكله يشتغل صح.

## الملفات (الجذر)
| الملف | الوظيفة |
|---|---|
| `indicators.py` | RSI, MACD, المتوسطات المتحركة، ATR، الدعم والمقاومة (بدون تسرّب بيانات مستقبلية) |
| `strategy.py` | الاستراتيجية الأصلية (TrendFollow) + حساب حجم الصفقة |
| `faisal_strategies.py` | استراتيجيتان من "دليل طريقة فيصل": الارتكاز وسحب السيولة |
| `backtest.py` | محاكاة التنفيذ وحساب الأداء |
| `run_backtest.py` | تشغيل سريع لاستراتيجية واحدة على رمز سهم |
| `compare_strategies.py` | **يقارن كل الاستراتيجيات جنب بعض على نفس الرمز والفترة** |
| `alpaca_executor.py` | التنفيذ الحقيقي عبر Alpaca — أوامر Limit + Bracket (وقف/هدف تلقائي على الوسيط) |
| `tests/` | مجموعة اختبارات pytest تثبّت كل الإصلاحات المكتشفة أثناء المراجعة |

### تشغيل الاختبارات
```bash
pip install pytest
pytest tests/ -v
```

### مقارنة الاستراتيجيات
```bash
python compare_strategies.py AAPL --capital 1000 --risk 0.01 --period 3y
```

## خطوات الوصول للتنفيذ الحي (بالترتيب)
1. **جرّب الباكتيست على عدة أسهم وفترات زمنية مختلفة** — لازم النتائج تكون منطقية قبل أي خطوة تالية. لا تنتقل للتنفيذ الحي إذا الاستراتيجية خسرانة أو النتائج غير ثابتة.
2. **افتح حساب Alpaca** (مجاني، بدون حد أدنى، يدعم السعودية): سجّل في alpaca.markets، فعّل التحقق بخطوتين، وابدأ بحساب Paper Trading أولًا (وهمي بالكامل، بدون فلوس حقيقية).
3. **شغّل التنفيذ التجريبي (Paper) لعدة أسابيع** قبل أي فلوس حقيقية، وقارن أداءه بالباكتيست.
4. **بعد الثقة بالنتائج**، انتقل لحساب حي بمبلغك الصغير (أقل من 1000$)، وابدأ بنسبة مخاطرة منخفضة جدًا (0.5%-1%).

## المرحلة 3: طبقة المراقبة والتقارير اليومية (مجلد `monitoring/`)

| الملف | الوظيفة |
|---|---|
| `trade_logger.py` | قاعدة بيانات SQLite تسجّل كل صفقة، إشارة، وخطأ |
| `report_generator.py` | يبني التقرير اليومي (نص + JSON للوحة + صورة منحنى رأس المال) |
| `telegram_notifier.py` | يرسل التقرير عبر بوت تيليجرام |
| `dashboard.py` + `templates/dashboard.html` | لوحة ويب محلية (منحنى رأس المال، الصفقات، الأخطاء) |
| `daily_runner.py` | **نقطة التشغيل اليومية** — تجمع كل شيء وتُجدوَل عبر cron |
| `claude_review.py` | تحليل تلقائي اختياري عبر Claude API (يحلل ويقترح فقط، لا يعدّل كود) |

### الإعداد
```bash
pip install -r requirements.txt

# مطلوب دائمًا
export EXECUTION_MODE="SIGNAL_ONLY"   # أو PAPER أو LIVE
export WATCHLIST="AAPL,MSFT,NVDA"     # الأسهم اللي تتابعها

# اختياري - أي استراتيجية تشغّل (لا تفعّل استراتيجيات فيصل حيًا إلا بعد ما تثبت نتائجها بالباكتيست)
export STRATEGY_NAME="trend_follow"   # trend_follow | base_track | liquidity_sweep

# اختياري - سقف عدد الصفقات المفتوحة بنفس الوقت (حماية مخاطرة على مستوى المحفظة كاملة)
export MAX_CONCURRENT_POSITIONS="3"

# مطلوب فقط إذا EXECUTION_MODE=PAPER أو LIVE
export ALPACA_API_KEY="..."
export ALPACA_SECRET_KEY="..."

# اختياري - تنبيهات تيليجرام (يستخدم بوتك الحالي أو بوت جديد)
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."

# اختياري - تحليل Claude التلقائي (تكلفة صغيرة جدًا لكل تشغيل، راجع platform.claude.com/docs للأسعار الحالية)
export ANTHROPIC_API_KEY="..."
export ENABLE_CLAUDE_REVIEW="true"
```

### التشغيل اليدوي (تجربة أولى)
```bash
python monitoring/daily_runner.py
```

### الجدولة التلقائية اليومية (مثال: 8 مساءً بعد إغلاق السوق، أيام الأسبوع)
```bash
crontab -e
# عدّل المسار لمسارك الفعلي:
0 20 * * 1-5  cd /path/to/trading_bot && python monitoring/daily_runner.py >> monitoring/run.log 2>&1
```

### لوحة الويب
```bash
python monitoring/dashboard.py
# افتح: http://localhost:5000
```
ينصح تعرضها عبر WireGuard بدل فتح بورت للعالم، بنفس فكرة راوترك الحالي.

### آلية المراجعة اليومية — نصف تلقائي مقابل تلقائي بالكامل
- **دائمًا يصير تلقائي:** توليد التقرير وإرساله لك عبر تيليجرام يوميًا، بغض النظر عن أي خيار تختاره.
- **نصف تلقائي (الافتراضي، مجاني):** تستلم التقرير، وتلصقه هنا في شات Claude وقت ما تحب تحليل أعمق أو نقاش إصلاح.
- **تلقائي بالكامل (اختياري):** فعّل `ENABLE_CLAUDE_REVIEW=true` فيرفق تحليل Claude تلقائيًا مع كل تقرير. هذا **تحليل واقتراحات فقط** — أي تعديل على الكود نفسه يبقى قرارك وتطبيقك يدويًا، لأن تعديل تلقائي غير مراقَب على كود يحرك فلوس حقيقية مخاطرة غير مبررة.

## اقتراحات تطوير لاحقة (اختيارية)
- **فلتر إطار زمني أعلى**: تأكيد الاتجاه على فريم أسبوعي قبل الدخول اليومي.
- **تنويع الأسهم**: ترتيب الأسهم بقائمة المتابعة حسب قوة الإشارة بدل معاملتها بالتساوي.
- **Bracket Orders في Alpaca**: تضع وقف الخسارة والهدف كجزء من الأمر نفسه بدل المراقبة اليدوية.

## النشر على VPS (مجلد `deploy/`)

الكود بايثون عادي بدون أي اعتماد خاص بجهاز معين — يشتغل على أي VPS فيه **Python 3.9+** (نفس فكرة VPS الـ vpnkit اللي عندك، Ubuntu مثلًا).

### خطوات النشر
```bash
# 1. انقل المجلد كامل للـ VPS (scp أو git)
scp -r trading_bot/ user@your-vps:/opt/

# 2. على الـ VPS
cd /opt/trading_bot
pip install -r requirements.txt --break-system-packages

# 3. جهّز ملف البيئة
cp deploy/.env.example deploy/.env
nano deploy/.env          # املأ مفاتيحك
chmod 600 deploy/.env     # يقرأه بس صاحب الملف

# 4. جرّب تشغيل يدوي أول مرة
bash deploy/run_daily.sh
```

### جدولة يومية عبر cron
كرون ما يقرأ `.env` تلقائيًا، فـ `run_daily.sh` يحمّلها بنفسه قبل التشغيل:
```bash
crontab -e
# عدّل المسار لو نقلت المجلد لمكان غير /opt/trading_bot:
0 20 * * 1-5  /opt/trading_bot/deploy/run_daily.sh >> /opt/trading_bot/monitoring/run.log 2>&1
```

### تشغيل اللوحة كخدمة دائمة (systemd)
```bash
sudo cp deploy/trading-dashboard.service /etc/systemd/system/
sudo nano /etc/systemd/system/trading-dashboard.service   # عدّل المسارات واسم المستخدم
sudo systemctl daemon-reload
sudo systemctl enable --now trading-dashboard
sudo systemctl status trading-dashboard   # للتأكد إنها شغالة
```
تشتغل تلقائيًا حتى بعد إعادة تشغيل الـ VPS، وتعيد نفسها تلقائيًا لو وقعت.

### تأمين اللوحة
لا تفتح بورت 5000 للعالم. اربطها بشبكة WireGuard الموجودة عندك (نفس أسلوبك بالراوتر) أو على الأقل قيّدها بجدار حماية (`ufw allow from <WireGuard-subnet> to any port 5000`).

## تحذير مهم
هذه أداة تحليل وتنفيذ آلي وليست نصيحة استثمارية. أي استراتيجية تفوز في الباكتيست قد تخسر في السوق الحي (فروقات التنفيذ، الانزلاق السعري، تغيّر سلوك السوق). ابدأ دائمًا بمبلغ يمكنك تحمّل خسارته بالكامل.
