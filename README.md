# لَبِنة — موقع ومعرض أعمال

مشروع ويب عربي كامل، بلا أي مكتبات خارجية، جاهز للنشر مجاناً.

| الملف | ما هو |
|---|---|
| `index.html` | **دليل القنوات** — المشروع الذي تعرضه للعملاء: بحث فوري، تصنيفات، وضع ليلي، يعمل بلا إنترنت |
| `portfolio.html` | **معرض أعمالك** — خدماتك وأسعارك وطرق التواصل. هذا هو الرابط الذي تضعه في ملفك على مستقل |
| `assets/brand.js` | **اسمك وبياناتك** — عدّل هنا فقط |
| `assets/channels.js` | قائمة القنوات — أضف واحذف بحرية |
| `assets/styles.css` | التصميم. غيّر `--accent` وحده لتتغيّر ألوان الموقع كله |
| `docs/freelance-kit.md` | **نصوص جاهزة** لملفك وعروضك على مستقل وخمسات |

---

## أولاً: ضع بياناتك (٥ دقائق)

افتح `assets/brand.js` وعدّل الأسطر المعلّمة بـ `←`:

```js
owner:   "اسمك هنا",          // ← اسمك الحقيقي
email:   "you@example.com",  // ← بريدك
whatsapp:"9665XXXXXXXX",     // ← رقمك بصيغة دولية بلا + ولا مسافات، مثل 966501234567
mostaql: "https://mostaql.com/u/USERNAME",
```

هذا وحده يكفي لتعمل كل أزرار التواصل في الموقع.

**إن أردت تغيير اسم العلامة من «لَبِنة» إلى غيره،** غيّر `name` و`latin` في نفس الملف، ثم غيّر
وسم `<title>` وسطر `og:title` في `portfolio.html` (سطران فقط).

---

## ثانياً: انشره مجاناً (١٠ دقائق)

اختر طريقة واحدة. كلها مجانية بلا حد زمني ولا بطاقة بنكية.

### الطريقة الأسهل — Cloudflare Pages

1. افتح [dash.cloudflare.com](https://dash.cloudflare.com) وأنشئ حساباً مجانياً.
2. من القائمة: **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**.
3. اربط حساب GitHub واختر مستودع `ew`.
4. في إعدادات البناء اترك كل شيء فارغاً:
   - Framework preset: **None**
   - Build command: **(اتركه فارغاً)**
   - Build output directory: **`/`**
5. اضغط **Save and Deploy**.

سيعطيك رابطاً مثل `ew-xyz.pages.dev` خلال دقيقة. وكل مرة تدفع فيها تعديلاً إلى GitHub سيُحدَّث الموقع تلقائياً.

### بديل — Netlify بالسحب والإفلات

افتح [app.netlify.com/drop](https://app.netlify.com/drop) واسحب مجلّد المشروع كاملاً إلى الصفحة. ينشر فوراً بلا حساب.

### بديل — GitHub Pages

من صفحة المستودع: **Settings** ← **Pages** ← في Source اختر **Deploy from a branch** ← الفرع `main` والمجلّد `/ (root)` ← **Save**.

> **مهم:** ميزة العمل بلا إنترنت (`sw.js`) تحتاج `https`. المنصّات الثلاث توفّره تلقائياً، لكنها لا تعمل عند فتح الملف من جهازك مباشرة.

---

## ثالثاً: اجعله يعمل لصالحك

1. ضع رابط `portfolio.html` في ملفك على **مستقل** و**خمسات** وفي وصف حسابك على تويتر/إنستغرام.
2. افتح `docs/freelance-kit.md` وانسخ منه نص ملفك الشخصي ونصوص عروضك.
3. قدّم على ٥ مشاريع يومياً في أول أسبوعين. العدد هنا أهم من الإتقان.

---

## تشغيله على جهازك

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ملاحظة قانونية

`index.html` دليل تنظيمي فقط ولا يستضيف أي بث؛ كل الروابط تفتح الصفحات الرسمية على
`elahmad.com`. **لا تضع إعلانات على هذه الصفحة تحديداً** — المحتوى ليس ملكك، وشبكات الإعلان
ترفض ذلك وقد يعترض صاحب الحقوق. اعرضها كعيّنة من مهارتك التقنية فقط، وهذا هو الغرض منها هنا.
