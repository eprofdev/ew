# بوت تداول يتعلّم

بوت تداول أسهم أمريكية يتعلّم من نتائج صفقاته: يسجّل حالة السوق لحظة كل إشارة،
ينتظر النتيجة، ويحدّث نموذجه — فيصير مع الوقت يرفض الإشارات اللي تشبه خسائره
السابقة، ويكبّر حجم اللي تشبه أرباحه.

**تحذير قبل كل شيء:** هذه أداة تحليل وتنفيذ آلي، وليست نصيحة استثمارية. أي
استراتيجية تفوز في الباكتيست قد تخسر في السوق الحي. ابدأ دائمًا بمبلغ يمكنك
تحمّل خسارته بالكامل.

---

## كيف يتعلّم؟ (الفكرة كاملة بصفحة واحدة)

الاستراتيجية تقول: **"هذي إشارة شراء."**
طبقة التعلّم تقول: **"بناءً على 137 صفقة سابقة تشبه هذي، احتمال نجاحها 38% — لا تدخلها."**

الدورة اليومية:

```
1. إشارة تصدر  →  نسجّل 22 رقمًا تصف حالة السوق بتلك اللحظة بالضبط
2. تمر أيام    →  نراقب السعر: وصل الوقف أولاً أم الهدف؟
3. النتيجة تظهر →  النموذج يتعلّم منها بخطوة تدريب واحدة
4. إشارة جديدة →  النموذج يعطيها احتمال نجاح، ومنه يتحدد: ندخل؟ وبأي حجم؟
```

الأهم: **الخطوة 2 تشتغل بلا أي حساب وسيط.** بوضع `SIGNAL_ONLY` البوت يستنتج
النتيجة من أسعار السوق الفعلية — فيتعلّم من اليوم الأول قبل ما تودع ريالًا واحدًا.

### ثلاث حمايات مبنية بالتصميم

| الحماية | ليش موجودة |
|---|---|
| **لا يرفع مخاطرتك أبدًا** | أقصى ما يسويه التعلّم هو تقليل `RISK_PCT`. الاحتمالات تقريبية، ورفع الحجم بناءً على تقدير متفائل أسرع طريق لتفجير الحساب. |
| **لا يفلتر قبل النضج** | تحت `LEARNING_MIN_SAMPLES` صفقة، النموذج يمرّر كل الإشارات. بوت يرفض صفقات بناءً على 9 عيّنات أسوأ من بوت بلا تعلّم. |
| **يسجّل ما رفضه أيضًا** | نتائج الصفقات المرفوضة تُحسب كذلك. لو كانت تربح أكثر من المقبولة، التقرير اليومي يقول لك صراحةً: **"الفلترة تضر حاليًا."** |

## البدء السريع

```bash
pip install -r requirements.txt

# 1. مفتاح بيانات (مجاني من twelvedata.com)
export DATA_PROVIDER=twelvedata
export TWELVEDATA_API_KEY="..."

# 2. نزّل البيانات مرة واحدة (يوفّر رصيدك بكل التجارب التالية)
python -m data.download AAPL,MSFT,NVDA,AMD,META,GOOGL,AMZN,TSLA --period 10y --out ./csv_data
export DATA_PROVIDER=csv DATA_CSV_DIR=./csv_data

# 3. درّب النموذج وشوف تقييمه الأمين
python train_model.py --symbols AAPL,MSFT,NVDA,AMD,META,GOOGL,AMZN,TSLA \
                      --period 10y --strategy all

# 4. شغّل دورة يومية واحدة (بلا تنفيذ، تعلّم فقط)
python monitoring/daily_runner.py
```

## اقرأ تقرير التدريب قبل أي شيء

`train_model.py` يطبع تقييمًا **خارج العيّنة** — يتنبأ بكل صفقة بنموذج ما شاف
إلا الصفقات اللي قبلها زمنيًا. السطر الحاسم فيه:

```
❌ النموذج لا يتفوق على التخمين الثابت — لا تفعّل الفلترة بعد.
```

لو ظهر هذا السطر، لا ترفع `LEARNING_THRESHOLD` فوق صفر مهما بدا جدول العتبات
مغريًا. أي "تحسّن" تشوفه حينها صدفة بالبيانات، وتثبيته كقاعدة تداول يحوّل ضجيجًا
عشوائيًا إلى خسائر دائمة. الأداة نفسها ترفض اقتراح عتبة في هذي الحالة.

وجدول العتبات يعطيك الرقم لو تفوّق النموذج فعلاً:

```
   عتبة    صفقات     ٪ باقية   فوز٪      متوسط R   مجموع R
   0.0     212       100.0     41.4      -0.167    -35.4
   0.45    131       61.8      53.8      +0.147    +19.3     ← المقترحة
   0.70    18        8.5       72.2      +1.210    +21.8     ← فخ: 18 صفقة فقط
```

انتبه لعمود `صفقات`: عتبة تترك 18 صفقة من 212 تبدو ممتازة وهي صدفة إحصائية.
الأداة ترفض اقتراح أي عتبة تُبقي أقل من 25 صفقة أو 40% من الإجمالي.

**عدد الرموز مهم:** استراتيجية على سهم واحد بـ10 سنوات تعطي 10-30 صفقة. نموذج
بـ22 خاصية على 20 صفقة يحفظ ولا يتعلّم. استخدم 8-15 سهمًا على الأقل.

## مصادر البيانات

| المزوّد | `DATA_PROVIDER` | ملاحظات |
|---|---|---|
| **Twelve Data** | `twelvedata` | واجهة رسمية بمفتاح. أسعار معدّلة للتجزئة والتوزيعات، حدّ معدّل تلقائي، وتخزين مؤقت يوفّر رصيدك. **موصى به.** |
| Yahoo Finance | `yahoo` | مجاني بلا مفتاح، لكن بلا ضمان خدمة — بعض الشبكات ومزوّدي VPS يحجبون نطاقاته فتفشل كل الطلبات. |
| ملفات محلية | `csv` | بلا شبكة ولا رصيد. نتائج قابلة لإعادة الإنتاج بالضبط. مثالي للتجارب المتكررة. |

> **مهم عند التبديل:** أعد تدريب النموذج بعد تغيير المزوّد. نموذج تعلّم على
> أسعار غير معدّلة للتوزيعات ثم شُغّل على معدّلة يقرأ خصائص بمقياس مختلف
> قليلاً عمّا تدرّب عليه — قريبة بما يكفي لتبدو سليمة، وبعيدة بما يكفي لتفسد القرارات.

## الوسطاء

| الوسيط | حساب تجريبي | أوامر Bracket | ملاحظات |
|---|---|---|---|
| **Alpaca** | ✅ | ✅ | وقف الخسارة والهدف يُسجَّلان عند الوسيط لحظة الدخول — يشتغلان حتى لو جهازك مطفي. **ابدأ من هنا.** |
| **Webull** | ❌ | ❌ | OpenAPI رسمي، لكن **بلا حساب تجريبي إطلاقًا** — أول أمر بفلوس حقيقية. وقف الخسارة يحتاج أمرًا منفصلاً بعد التنفيذ. |

### تحذير Webull بالتفصيل

1. **لا يوجد Paper Trading.** أي أمر عبر `brokers/webull.py` بفلوس حقيقية. لهذا
   يفرض الكود متغيّر تأكيد صريح `WEBULL_CONFIRM_LIVE=yes` قبل أول أمر، ويرفض
   `EXECUTION_MODE=PAPER` مع Webull بخطأ واضح بدل ما يعطيك إحساسًا كاذبًا بالأمان.
2. **لا Bracket Orders.** بين لحظة تنفيذ الشراء وأول تشغيلة بعدها يبقى مركزك
   بلا وقف خسارة مسجّل. `ensure_protective_stop()` تغطي الفجوة كل تشغيلة —
   شغّل `daily_runner` أكثر من مرة يوميًا لو تنفّذ عبر Webull.
3. **يحتاج اعتماد تطبيق** من بوابة مطوّري Webull، والتوفّر يختلف حسب سوقك
   (US / HK / JP). بعض الواجهات غير متاحة لعملاء Webull US حتى الآن.

**التوصية:** جرّب على Alpaca Paper أسابيع أولاً، حتى لو نيّتك النهائية Webull.

## التشغيل اليومي

```bash
# الإعداد (انسخ deploy/.env.example إلى .env وعدّله، فيه كل الخيارات موثّقة)
export EXECUTION_MODE=SIGNAL_ONLY
export WATCHLIST="AAPL,MSFT,NVDA"
export ENABLE_LEARNING=true
export LEARNING_THRESHOLD=0.0        # ارفعها فقط بناءً على تقرير التدريب

python monitoring/daily_runner.py
```

الجدولة عبر cron (8 مساءً بعد إغلاق السوق، أيام الأسبوع):

```bash
crontab -e
0 20 * * 1-5  /opt/trading_bot/deploy/run_daily.sh >> /opt/trading_bot/monitoring/run.log 2>&1
```

### الاختيار التلقائي للاستراتيجية

```bash
export STRATEGY_NAME=auto
```

يسحب Thompson Sampling من توزيع أداء كل استراتيجية ويشغّل صاحب أعلى سحبة.
النتيجة: القوية تُختار أغلب الوقت، والضعيفة تُجرَّب أحيانًا — فلو تغيّر السوق
لصالحها يُكتشف ذلك بدل ما تعلق على اختيار قديم للأبد. المكافأة على R (الربح ÷
المخاطرة) لا على نسبة الفوز.

## الاختبارات

```bash
pytest tests/ -v
```

139 اختبارًا تغطي الأشياء اللي لو انكسرت بصمت تكلّفك فلوسًا:

- **تسرّب البيانات المستقبلية** — تُحسب خصائص شمعة مرتين، مرة على البيانات
  كاملة ومرة على بيانات مقصوصة عندها؛ أي اختلاف يعني أن الكود يقرأ المستقبل.
- **أمانة التقييم** — مراقبة فعلية تتأكد أن النموذج وقت التنبؤ بالصفقة رقم i
  تدرّب على i صفقة بالضبط، ولا واحدة أكثر.
- **حدود الأمان** — التعلّم لا يتجاوز `RISK_PCT`، ولا يفلتر قبل النضج، ولا
  يعطّل البوت عند أي عطل (نموذج تالف، خصائص مفقودة، ملف ناقص).
- **التركيبات الخطرة** — `EXECUTION_MODE=PAPER` مع Webull تُرفض بخطأ صريح.
- **توحيد شكل البيانات** — عمود ناقص أو فهرس تنازلي يوقف التشغيل بخطأ واضح
  بدل ما ينتج مؤشرات غلط بصمت.

## خطوات الوصول للتنفيذ الحي (بالترتيب)

1. **باكتيست على عدة أسهم وفترات.** لا تنتقل لو النتائج خسرانة أو غير ثابتة.
2. **درّب النموذج واقرأ تقييمه.** لو ما تفوّق على التخمين الثابت، شغّل بعتبة 0
   واترك البوت يجمع دروسًا حقيقية.
3. **شغّل `SIGNAL_ONLY` أسابيع.** يتعلّم بلا أي مخاطرة مالية إطلاقًا.
4. **افتح حساب Alpaca Paper** (مجاني، بدون حد أدنى، يدعم السعودية) وشغّله
   `PAPER` عدة أسابيع، وقارن أداءه بالباكتيست.
5. **بعد الثقة**، انتقل لحساب حي بمبلغ صغير ونسبة مخاطرة 0.5%-1%.

## النشر على VPS

الكود بايثون عادي — يشتغل على أي VPS فيه Python 3.9+.

```bash
scp -r trading_bot/ user@your-vps:/opt/
cd /opt/trading_bot
pip install -r requirements.txt --break-system-packages

cp deploy/.env.example deploy/.env
nano deploy/.env          # املأ مفاتيحك
chmod 600 deploy/.env     # يقرأه بس صاحب الملف

bash deploy/run_daily.sh  # تجربة يدوية أولى
```

لوحة الويب كخدمة دائمة:

```bash
sudo cp deploy/trading-dashboard.service /etc/systemd/system/
sudo nano /etc/systemd/system/trading-dashboard.service   # عدّل المسارات والمستخدم
sudo systemctl daemon-reload
sudo systemctl enable --now trading-dashboard
```

**لا تفتح بورت 5000 للعالم.** اربطها بشبكة WireGuard أو قيّدها بجدار حماية:
`ufw allow from <WireGuard-subnet> to any port 5000`.

## المراجعة اليومية — نصف تلقائي مقابل تلقائي بالكامل

- **دائمًا تلقائي:** توليد التقرير وإرساله لك بتيليجرام يوميًا، مع ملخص حالة
  التعلّم (كم درسًا جمع، هل النموذج ناضج، هل الفلترة تنفع أو تضر).
- **نصف تلقائي (الافتراضي، مجاني):** تستلم التقرير وتلصقه بشات Claude وقت ما
  تحب تحليلًا أعمق.
- **تلقائي بالكامل (اختياري):** `ENABLE_CLAUDE_REVIEW=true` يرفق تحليل Claude
  مع كل تقرير. هذا **تحليل واقتراحات فقط** — أي تعديل على الكود يبقى قرارك
  وتطبيقك يدويًا، لأن تعديلاً تلقائيًا غير مراقَب على كود يحرّك فلوسًا حقيقية
  مخاطرة غير مبررة.
